System requirements

Windows and runtime components.

Windows 10 and Windows 11 on x64 systems are supported. Other Windows versions and ARM64 systems have not been tested and are not supported. The latest Microsoft Visual C++ v14 Redistributable for x64 is also required; xucRun needs no additional third-party service. If the runtime is missing, the installer offers the verified Microsoft download, selection of an existing vc_redist.x64.exe, or cancellation.

Windows UAC must be enabled system-wide. Elevated launches under another administrator account additionally require Admin Approval Mode to be enabled for that account. UAC requirement details

Installation

Run and configure the installer.

The provided installer is not Authenticode-signed. Windows may therefore report an unknown publisher when it is first started.

As an optional check, the installer's SHA-256 hash can be compared with its entry in SHA256SUMS.txt from the same release. Do not run the file if the values differ.

Get-FileHash .\xucRun-Installer-<Version>-x64.exe -Algorithm SHA256
  1. Start the downloaded installer file and confirm User Account Control.
  2. Change the preselected language if needed and choose whether the installer should add xucRun to the Windows program search path.

With the search path option enabled, xucrun can be invoked from new consoles without specifying its full path.

Local signing of the components is automatic.

The installation guide covers updates, uninstallation, and manual installation.
