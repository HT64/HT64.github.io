Installation background

Local signing.
Automatic during installation.

The graphical installer handles verification and local signing of the included components.

View the process Open download page

Security boundary

Download origin

Local signing does not establish the origin of the download. The installer verification procedure is on the download page.

Design decision

Machine-local signature trust.

The included Core components are signed with a self-signed developer certificate. If this certificate were installed as a trust anchor on the target computer, Windows would also trust other files signed with the same developer certificate.

Instead, xucRun installs a machine-local certificate as a trust anchor. The developer certificate is not installed as a trust anchor, so a later compromise of its key does not automatically extend local signature trust.

01 · Verify

Verify embedded signatures

The installer checks that the included Core files are complete and share the same intended signer.

02 · Sign

Sign temporary copies

It re-signs the components with the local certificate. No online timestamp service is required.

03 · Install

Install the verified package

The components are installed only after every new signature is valid and matches the local certificate.

Scope

These Core files are signed.

  • xucRun.exe, xucRunBroker.exe, and xucRunApproval.exe
  • the two Core language DLLs below Languages
  • Install-xucRun.ps1

The optional Tray is installed separately and uses the same local certificate.

The installation guide describes manual installation.

Local certificate

The key stays on this computer.

RSA 3072 · SHA-256

Non-exportable and reusable

The Core installer reuses an existing valid xucRun certificate, including during updates. Otherwise, it creates a new one with a non-exportable private key in the local computer certificate store. A different computer receives its own local identity.

Do not continue

Any mismatch is a stop signal.

Do not install the package if embedded files are missing, signers differ, or an existing signature cannot be verified. Delete the file and download the official release again.

The Windows SDK and signtool.exe are not required for the user workflow.
