Offizielles GitHub Release

Lade den Installer ausschließlich aus dem offiziellen GitHub Release herunter und vergleiche vor dem Start die dort veröffentlichte SHA-256-Prüfsumme. Die Installer-Datei besitzt keine Signatur eines öffentlich vertrauenswürdigen Herausgebers; Windows kann deshalb einen unbekannten Herausgeber melden.

Unterstützt werden Windows 10 und Windows 11 auf x64-Systemen. Zusätzlich ist die aktuelle Microsoft Visual C++ v14 Redistributable für x64 erforderlich. Fehlt sie, bietet der Installer den geprüften Microsoft-Download oder die Auswahl einer vorhandenen vc_redist.x64.exe an.

Optionales Add-on

xucRun Tray

Das optionale xucRun Tray ist ebenfalls Open Source. Es ergänzt eine Status- und Bedienoberfläche im Windows-Infobereich und benötigt eine installierte xucRun-Version mit exakt derselben vierteiligen Versionsnummer.

Aktuelles xucRun-Tray-Release · Alle Tray-Releases

01

Installationspaket

Die signierte xucRun-Installer-<Version>-x64.exe enthält xucRun, Broker, Approval-Helper und beide Sprachen. <Version> steht für die im gewählten Release angegebene Versionsnummer. Eine einzeln kopierte xucRun.exe reicht für Starts mit gespeicherten Anmeldedaten nicht aus.

02

Integrität prüfen

Vergleiche vor der Installation die beim Release veröffentlichte SHA-256-Prüfsumme:

Get-FileHash .\xucRun-Installer-<Version>-x64.exe -Algorithm SHA256

03

Selbstsigniertes Zertifikat

Der Installer und seine enthaltenen Dateien sind derzeit mit einem selbstsignierten Zertifikat digital signiert. Dadurch sind nachträgliche Dateiänderungen erkennbar, Windows kann den Herausgeber jedoch nicht automatisch über eine öffentliche Zertifizierungsstelle bestätigen.

Das Zertifikat erzeugt keine öffentliche Microsoft-SmartScreen-Reputation. Deshalb können Windows und SmartScreen trotz unveränderter Signatur eine Warnung zu einem unbekannten Herausgeber oder einer unbekannten App anzeigen.

04

Lokales Standardzertifikat

Der Core-Installer erzeugt nach erfolgreicher Prüfung automatisch ein eigenes, nicht exportierbares Zertifikat auf dem Zielrechner oder verwendet das vorhandene gültige xucRun-Standardzertifikat erneut. Eine Auswahl zur Installation des Entwicklerzertifikats gibt es nicht.

Die lokale Signierung begrenzt das dauerhafte Vertrauen auf den jeweiligen Rechner: Eine spätere Kompromittierung des Entwicklerzertifikats macht damit signierte Dateien dort nicht automatisch vertrauenswürdig.

Der separate Tray-Installer verwendet dasselbe bereits vorhandene Core-Zertifikat. Beide Installer akzeptieren nur zusammengehörige Dateien mit dem vorgesehenen gemeinsamen Signierer. Der private Entwicklerschlüssel wird niemals verteilt.

Lokale Signierung Schritt für Schritt

Installation

Erst prüfen, dann installieren.

  1. Die aktuelle xucRun-Installer-<Version>-x64.exe aus dem offiziellen GitHub Release herunterladen.
  2. Die in den Release Notes veröffentlichte SHA-256-Prüfsumme vergleichen.
  3. Die heruntergeladene Installer-Datei starten und die Benutzerkontensteuerung bestätigen.
  4. Sprache und PATH-Option auswählen. Das lokale xucRun-Standardzertifikat wird automatisch erstellt oder wiederverwendet.
.\xucRun-Installer-<Version>-x64.exe

Die ausführliche Anleitung zur lokalen Signierung erklärt das maschinenlokale Vertrauensmodell. Das optionale xucRun Tray wird anschließend mit derselben vierteiligen Versionsnummer wie der installierte Core eingerichtet.

Bitte lies vor Download und Nutzung die Hinweise zu Einsatzbereich, Sicherheitsgrenzen und möglichen Risiken.
